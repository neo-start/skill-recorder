All recordings live in `chrome.storage` / IndexedDB on your machine. Clearing the extension's data via `chrome://extensions` deletes everything immediately. No remote copy exists.

16:T17e2,<h1 id="using-with-claude-code">Using with Claude Code</h1>
<p>The output <code>SKILL.md</code> is designed for <a href="https://docs.claude.com/claude-code">Claude Code</a> running the <a href="https://github.com/browserbase/skills"><code>browse</code></a> skill from the Browserbase skill marketplace.</p>
<h2 id="prerequisites">Prerequisites</h2>
<p>Make sure <code>browse</code> is installed and Claude Code knows about it:</p>
<pre class="shiki github-dark-dimmed" style="background-color:#22272e;color:#adbac7" tabindex="0"><code><span class="line"><span style="color:#768390"># in your Claude Code session:</span></span>

<pre class="shiki github-dark-dimmed" style="background-color:#22272e;color:#adbac7" tabindex="0"><code><span class="line"><span style="color:#F69D50">npm</span><span style="color:#96D0FF"> install</span><span style="color:#6CB6FF"> -g</span><span style="color:#96D0FF"> @browserbasehq/browse-cli</span></span></code></pre>
<h2 id="the-mapping">The mapping</h2>
<p>Each line in your generated SKILL.md is a real shell command Claude Code can run:</p>
<p>| SKILL.md step | <code>browse</code> invocation | |---|---| | navigate | <code>browse open &lt;url&gt;</code> | | fill | <code>browse fill &lt;selector&gt; &lt;value&gt;</code> (auto-presses Enter) | | click | <code>browse snapshot</code> + <code>browse click &lt;ref&gt;</code> | | press_key | <code>browse press &lt;key&gt;</code> | | submit | <code>browse snapshot</code> + <code>browse click &lt;submit-ref&gt;</code> | | scroll | <code>browse scroll 0 0 0 &lt;dy&gt;</code> |</p>

<h2 id="on-failure">On failure</h2>
<p>The generated <code>## On failure</code> section instructs the agent to:</p>
<p>1. Re-snapshot when a selector misses, and re-locate by aria-label / role / visible text 2. Try alternate <strong>Selector hints</strong> in order 3. Stop rather than blindly continue when an <code>Expected:</code> line diverges from observed state 4. Re-pick rather than reuse the recorded selector on steps marked ⚠️ (dynamic-list items)</p>
<p>This is what makes the file degrade gracefully across page redesigns and parameter changes.</p>
