d:T536,## What we collect

**Nothing on our servers.** Skill Recorder is a Chrome extension that records browser activity locally and saves the result into your own browser's IndexedDB and your local Downloads folder. We do not operate a backend that ingests your recordings.

## What the website collects

This marketing website may use [PostHog](https://posthog.com) to capture anonymous page-view events when an opt-in cookie banner is accepted. No personal data is sent without consent.

## What the extension transmits

The extension does not transmit any of your recordings, action logs, or distilled SKILL.md files to any remote server. The cloud-sync feature in the roadmap is opt-in and will be documented separately when shipped.

## What you control

All recordings live in `chrome.storage` / IndexedDB on your machine. Clearing the extension's data via `chrome://extensions` deletes everything immediately. No remote copy exists.

## Third parties

- **Cloudflare Pages** hosts this site and may log standard HTTP metadata for security purposes.
- **PostHog** (optional, EU-hosted) collects anonymous product analytics when the cookie banner is accepted.

No other third parties receive your data.

16:Tfaa,<h1 id="getting-started">Getting started</h1>
<p>Skill Recorder is a Chrome extension that turns a browser demo into a <a href="https://docs.claude.com/claude-code">Claude Code</a> <code>SKILL.md</code>. The output is a portable markdown file an AI agent can re-run autonomously via the <a href="https://github.com/browserbase/skills"><code>browse</code></a> CLI.</p>
<h2 id="install">Install</h2>
<p>Until we ship to the Chrome Web Store, you need to load the unpacked extension:</p>
<pre class="shiki github-dark-dimmed" style="background-color:#22272e;color:#adbac7" tabindex="0"><code><span class="line"><span style="color:#F69D50">git</span><span style="color:#96D0FF"> clone</span><span style="color:#96D0FF"> git@github.com:neo-start/skill-recorder.git</span></span>
<span class="line"><span style="color:#6CB6FF">cd</span><span style="color:#96D0FF"> skill-recorder</span></span>
<span class="line"><span style="color:#F69D50">pnpm</span><span style="color:#96D0FF"> install</span></span>
<span class="line"><span style="color:#F69D50">pnpm</span><span style="color:#6CB6FF"> --filter</span><span style="color:#96D0FF"> @skill-recorder/crx</span><span style="color:#96D0FF"> build</span></span></code></pre>
<p>Then in Chrome:</p>
<p>1. Open <code>chrome://extensions</code> 2. Toggle <strong>Developer mode</strong> on 3. Click <strong>Load unpacked</strong> 4. Select <code>projects/skill-recorder/apps/crx/dist/</code> 5. Pin the extension; click the icon to open the side panel</p>
<h2 id="record-your-first-flow">Record your first flow</h2>
<p>1. Navigate to the site you want to demo 2. Click the Skill Recorder icon → <strong>Start recording</strong> 3. Do the flow once. The side panel shows a live action counter 4. <strong>Stop recording</strong> when you're done</p>
<blockquote>Avoid navigating to a <em>different</em> domain mid-recording — one full-page nav away ends the rrweb context.</blockquote>
<h2 id="export-a-skill">Export a Skill</h2>
<p>1. Find your recording in the side panel 2. Click <strong>Save as Skill</strong> 3. The dialog auto-detects every typed value as a parameter, strips noise (redundant submit clicks, extra Enter presses), and flags clicks on dynamic-list items 4. Click <strong>Download SKILL.md</strong> — the file lands in <code>~/Downloads/skill-recorder-skills/&lt;slug&gt;-&lt;timestamp&gt;.SKILL.md</code></p>
<h2 id="hand-it-to-claude-code">Hand it to Claude Code</h2>
<p>Move the file into a Claude Code skill directory:</p>
<pre class="shiki github-dark-dimmed" style="background-color:#22272e;color:#adbac7" tabindex="0"><code><span class="line"><span style="color:#F69D50">mkdir</span><span style="color:#6CB6FF"> -p</span><span style="color:#96D0FF"> ~/.claude/skills/</span><span style="color:#F47067">&#x3C;</span><span style="color:#96D0FF">your-skill-nam</span><span style="color:#ADBAC7">e</span><span style="color:#F47067">></span></span>
<span class="line"><span style="color:#F69D50">mv</span><span style="color:#96D0FF"> ~/Downloads/skill-recorder-skills/</span><span style="color:#6CB6FF">*</span><span style="color:#96D0FF">.SKILL.md</span><span style="color:#F47067"> \</span></span>
<span class="line"><span style="color:#96D0FF">   ~/.claude/skills/</span><span style="color:#F47067">&#x3C;</span><span style="color:#96D0FF">your-skill-nam</span><span style="color:#ADBAC7">e</span><span style="color:#F47067">></span><span style="color:#96D0FF">/SKILL.md</span></span></code></pre>
<p>In your next Claude Code session, the agent will autoload it and can run the flow via the <code>browse</code> CLI.</p>
