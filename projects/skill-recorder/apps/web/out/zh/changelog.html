更新日志

每个发布到 dist/ 的版本,最新在上。

v0.1.19

2026-05-12

New

  • Auth Precondition rendering. When the recording crosses a known auth provider or a password input is filled, the exported SKILL.md now emits a ## Precondition block with concrete browse --context-id commands so the AI agent can load a pre-authed Browserbase context instead of trying to log in itself.
  • Manual auth toggle. A new "Requires authenticated session" checkbox in the Save-as-Skill dialog lets you flag recordings where you were already signed in (the auto-detector can't see that).

Improved

  • Fingerprint dedup. Visible-label texts like "Text to MindmapText to Mindmap" (caused by sr-only sibling concat) collapse to a single "Text to Mindmap" — both in the recorded action log and at resolve time.
  • Dynamic-list heuristic tightened. The ⚠️ warning no longer fires on every deep-DOM click; it now requires positive evidence (:nth-of-type in the top selector or a known container class like s-card-container, puis-card, gridcell).

v0.1.18

2026-05-11

New

  • ⚠️ dynamic-list-item warning. When a click step's selectors look like a search-result/grid item (CSS contains :nth-of-type, deep positional xpath, or known result-container class names), the rendered SKILL.md now annotates the step with a warning telling the agent to re-pick instead of reusing the recorded selector verbatim.

Improved

  • Distillation skip heuristics. Default-skip Enter key presses on an empty text input (recording artifact), and the redundant submit click that follows a browse fill (which already presses Enter).
