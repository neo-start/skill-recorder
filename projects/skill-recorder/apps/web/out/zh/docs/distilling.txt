14:Teb0,<h1 id="skill">蒸馏 skill</h1>
<p>在 sidepanel 点 <strong>Save as Skill</strong>,原始 <code>ActionStep[]</code> 会变成一组可编辑的 <code>DraftStep</code>。每条 draft 有 <code>action</code>、<code>intent</code>、<code>skipped</code> 开关,以及(对 fill)<code>isParam</code> / <code>paramName</code>。</p>
<h2 id="">默认跳过启发式</h2>
<p>真实用户总会产生很多噪音。弹窗默认勾掉这些,但每一条仍然可见,一键就能重新勾回来。</p>
<p>| 模式 | 跳过原因 | |---|---| | <code>scroll</code> 事件 | 点击流里几乎不是有意的 | | <code>keyUp</code> 事件 | 回放只需 <code>keyDown</code> | | Backspace / Delete | 后面会有 <code>fill</code> 覆盖,清空无意义 | | 连续重复同一键 | 用户长按 Enter | | <code>keyDown Enter</code> 紧跟在文本框 click 之后,中间无 change | 纯录制噪音 | | <code>click</code> 跟在 <code>change</code> 后 3 秒内,目标是 submit-like 按钮 | <code>browse fill</code> 自带 Enter,这次点击是重复的 | | <code>navigate</code> 跟在 click / submit / change / Enter 后 5 秒内 | 副作用的重定向链 |</p>
<h2 id="">参数检测</h2>
<p>每条非 masked 的 <code>fill</code> 默认被标为参数。参数名从 input 的 <code>aria-label</code> 或可见 label 推断(<code>Search Amazon.sg</code> → <code>search_amazonsg</code>)。你可以取消勾选改成字面量,或者直接重命名。同名参数会被合并为同一个 <code>SkillParameter</code>。</p>
<h2 id="">⚠️ 动态列表项警告</h2>
<p>当一个 click 的 selector 看起来是搜索结果或网格项(top selector 含 <code>:nth-of-type</code>,或选择器链含已知容器类名 <code>s-card-container</code> / <code>puis-card</code> / <code>product-card</code> / <code>gridcell</code>),渲染器会在这步前插入警告,提示 AI agent <strong>重新挑选</strong>而不是死用录制 selector。这样可以避免「录制时搜的是 X、回放时搜的是 Y,字面 product selector 直接 miss」的经典失败。</p>
<h2 id="auth-precondition">Auth Precondition</h2>
<p>弹窗扫描录制里的登录信号:</p>
<ul><li>在密码框上的 <code>change</code></li><li><code>navigate</code> 到已知 auth provider 域(<code>logto.app</code>、<code>auth0.com</code>、<code>accounts.google.com</code>、<code>appleid.apple.com</code>、<code>login.microsoftonline.com</code>、<code>okta.com</code>、<code>clerk.dev</code>、<code>firebaseapp.com</code>…)</li><li><code>navigate</code> 到 auth 风格的路径(<code>/login</code>、<code>/signin</code>、<code>/oauth</code>、<code>/authorize</code>、<code>/register</code>…)</li></ul>
<p>任一信号命中,<strong>Requires authenticated session</strong> 复选框会自动勾上,渲染的 SKILL.md 顶部会插入 <code>## Precondition</code> 段,告诉 agent 加载预登的 Browserbase context。你也可以手动勾选——录制时本就已经登录的情况自动检测抓不到。</p>
<h2 id="expectation">Expectation 推导</h2>
<p>每条留下的步骤会看下一步,推导出一条 <code>Expected:</code>:</p>
<ul><li>下一步换了 URL → <code>URL becomes &lt;新 URL&gt;</code></li><li>下一步有 target selector → <code>&quot;&lt;目标&gt;&quot; becomes interactable</code></li></ul>
<p>这条既会作为渲染 markdown 里每步下面的 <code><strong>Expected:</strong></code>,也会成为扩展内回放的验证条件。</p>
