14:T16b6,<h1 id="claude-code">配合 Claude Code</h1>
<p>输出的 <code>SKILL.md</code> 是为 <a href="https://docs.claude.com/claude-code">Claude Code</a> + Browserbase 的 <a href="https://github.com/browserbase/skills"><code>browse</code></a> skill 而设计的。</p>
<h2 id="">准备</h2>
<p>确认 <code>browse</code> 已安装且 Claude Code 知道它:</p>
<pre class="shiki github-dark-dimmed" style="background-color:#22272e;color:#adbac7" tabindex="0"><code><span class="line"><span style="color:#768390"># 在 Claude Code session 里:</span></span>
<span class="line"><span style="color:#F69D50">/plugin</span><span style="color:#96D0FF"> marketplace</span><span style="color:#96D0FF"> add</span><span style="color:#96D0FF"> browserbase/skills</span></span>

<p>或者直接全局装 CLI:</p>
<pre class="shiki github-dark-dimmed" style="background-color:#22272e;color:#adbac7" tabindex="0"><code><span class="line"><span style="color:#F69D50">npm</span><span style="color:#96D0FF"> install</span><span style="color:#6CB6FF"> -g</span><span style="color:#96D0FF"> @browserbasehq/browse-cli</span></span></code></pre>
<h2 id="">命令映射</h2>
<p>SKILL.md 里的每个 step 都是真实可执行的 shell 命令:</p>
<p>| SKILL.md 步骤 | <code>browse</code> 调用 | |---|---| | navigate | <code>browse open &lt;url&gt;</code> | | fill | <code>browse fill &lt;selector&gt; &lt;value&gt;</code>(自动按 Enter) | | click | <code>browse snapshot</code> + <code>browse click &lt;ref&gt;</code> | | press_key | <code>browse press &lt;key&gt;</code> | | submit | <code>browse snapshot</code> + <code>browse click &lt;submit-ref&gt;</code> | | scroll | <code>browse scroll 0 0 0 &lt;dy&gt;</code> |</p>

<span class="line"><span style="color:#768390"># 返回 {"id": "ctx_xxx", ...}</span></span>
<span class="line"></span>
<span class="line"><span style="color:#F47067">export</span><span style="color:#ADBAC7"> CLIPMIND_CTX</span><span style="color:#F47067">=</span><span style="color:#ADBAC7">ctx_xxx     </span><span style="color:#768390"># 名字按录制 domain 自动派生</span></span>

<h2 id="">失败处理</h2>
<p>生成的 <code>## On failure</code> 段会指导 agent:</p>
<p>1. selector 失效时重新 snapshot,按 aria-label / role / 可见文字定位 2. 按顺序试备选 <strong>Selector hints</strong> 3. 看到 <code>Expected:</code> 与现状不符就停下,不要盲目继续 4. 对标 ⚠️ 的步骤(动态列表项)重新挑选,而不是死用录制 selector</p>
<p>这套逻辑让 skill 在页面改版或参数变化时优雅退化。</p>
